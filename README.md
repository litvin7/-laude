# Peep & Peak 🤎

Информационная страница об именных видео-поздравлениях с парой капибар Peep & Peak. Без форм: клиенты пишут в директ Instagram.

Сайт — один файл `index.html` и картинки в `images/frames/`. Раздаётся через GitHub Pages: https://litvin7.github.io/-laude/

## Что поменять

В конце `index.html` есть блок `CONFIG`:

- `instagram` — ник в Instagram (кнопки ведут в директ);
- `tiers` — цены: длительность и цена (названия и описания — в переводах);
- `videos` — ссылки на YouTube Shorts с примерами;
- `ideaImages` — картинки для блока идей;
- `reels` — кадры для ленты на первом экране.

## Языки

Сайт на 9 языках: английский (по умолчанию), китайский, хинди, испанский, французский, арабский (справа налево), бенгальский, португальский, русский. Язык выбирается автоматически по языку браузера, его можно сменить в шапке, выбор запоминается. Ссылка на конкретный язык: `?lang=ru`, `?lang=es` и т. д.

Все тексты лежат в `I18N` внутри `index.html`, по одному блоку на язык.

## Публикация

GitHub Pages: Settings → Pages → ветка с сайтом, папка `/ (root)`. Каждый пуш обновляет сайт через 1–2 минуты. Свой домен подключается там же (Custom domain).
