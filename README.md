# Peep & Peak 🤎

Сайт-визитка Peep & Peak и три направления. Без форм: все кнопки ведут в директ Instagram. Раздаётся через GitHub Pages: https://litvin7.github.io/-laude/

## Страницы

| Адрес | Что это |
| --- | --- |
| `/` (`index.html`) | Визитка: три карточки-направления, кнопка в директ, соцсети |
| `/greetings/` | Именные видео-поздравления с капибарами: примеры, цены, идеи |
| `/video/` | Peep снимает любые ролики с ИИ: реклама, кино, клипы |
| `/dev/` | Peep-программист: Telegram-боты, сайты, автоматизация, DeFi |

Картинки лежат в `images/frames/`.

## Ссылки на соцсети

Все ссылки (Instagram, директ, YouTube, TikTok, Telegram) задаются в одном месте: блок `SITE` в начале `assets/site.js`. Его используют визитка, `/video/` и `/dev/`.

У `/greetings/` свой блок `CONFIG` в конце `greetings/index.html`: ник Instagram, цены, ссылки на YouTube Shorts с примерами, картинки.

## Языки

Все страницы на 9 языках: английский (по умолчанию), китайский, хинди, испанский, французский, арабский (справа налево), бенгальский, португальский, русский. Язык выбирается по языку браузера, его можно сменить в шапке, выбор запоминается и действует на всех страницах. Выпадающее меню языков общее для всех страниц: `assets/lang-menu.js`, цвета под каждую страницу задаются переменными `--lm-*`. Ссылка на конкретный язык: `?lang=ru`, `?lang=es` и т. д.

Тексты лежат в `window.I18N` внутри каждой страницы, по одному блоку на язык.

## Публикация

GitHub Pages: Settings → Pages → ветка с сайтом, папка `/ (root)`. Каждый пуш обновляет сайт через 1–2 минуты. Свой домен подключается там же (Custom domain).
