# Peep & Peak 🤎

Лендинг для именных ИИ-видео с парой капибар. Весь сайт состоит из одного файла `index.html`: без сборки, без сервера, без хостинга.

## Что поменять под себя

В конце `index.html` есть блок `CONFIG`:

- `instagram` — ваш ник без @;
- `telegram` — ник в Telegram (необязательно);
- `telegramChannel` — ссылка на Telegram-канал со скидкой −40%;
- `plans` — видео 30/60/90 сек: `price` — обычная цена, `sub` — цена для подписчиков Telegram-канала;
- `ownIdea` — доплата за «Свою историю» (скидка на неё не действует);
- `occasions` — поводы в форме и на сайте;
- `urgentDays` — если до даты меньше стольких дней, форма предупреждает о срочном заказе;
- `whatsapp` — ваш номер для кнопки «написать в WhatsApp» (необязательно);
- `examples` — примеры: `img` — обложка, `youtube` — ссылка на YouTube (видео откроется прямо на сайте), `url` — ссылка в Instagram;
- `ideas` и `reels` — кадры для блока идей и ленты на первом экране (файлы в `images/frames/`);
- `leadEndpoint` — адрес Cloudflare Worker, через который заявки уходят в Telegram (инструкция в `worker/README.md`).

Клиент в заявке обязательно выбирает, как с ним связаться: Instagram, Telegram или WhatsApp. Затем вводит ник или номер, и форма проверяет, что он введён правильно.

## Публикация бесплатно (GitHub Pages)

1. Репозиторий должен быть **публичным** (на бесплатном аккаунте Pages работает только для публичных репозиториев).
2. Откройте Settings → Pages.
3. Source: **Deploy from a branch**, затем выберите ветку с сайтом и папку `/ (root)` и нажмите Save.
4. Через 1–2 минуты сайт появится по адресу `https://<ваш-ник>.github.io/<репозиторий>/`.

## Заявки в Telegram-бот

Токен бота нельзя класть в код публичного сайта. Заявки отправляются через бесплатный Cloudflare Worker, где токен хранится в секрете. Пошаговая инструкция: `worker/README.md`.

## Аналитика и cookie-баннер

Впишите ID в `CONFIG`: `metaPixelId`, `yandexMetrikaId`, `googleAnalyticsId`. Счётчики загружаются только после того, как посетитель нажмёт «Принять» в cookie-баннере. Пока ни один ID не указан, баннер не показывается.

Когда заявка отправлена, сайт передаёт событие «заявка» в каждую подключённую систему: `Lead` в Meta, цель `lead` в Метрике, `generate_lead` в Google Analytics. В Яндекс Метрике создайте цель типа «JavaScript-событие» с идентификатором `lead`.
